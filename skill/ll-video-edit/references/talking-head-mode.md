# 已录人物口播视频模式

仅在用户提供带人物和原声的口播视频、并希望制作完整 16:9 动效成片时读取。仍按 `six-step-workflow.md` 的六步确认节点执行；本文件只写与逐字稿模式不同的部分。

## 第一步：从原片建立可信输入

1. 用 ffprobe 检查原片能否读取、视频比例、帧率、时长及音轨。原片可为 3:4 等比例；最终成片仍为 1920×1080、16:9，不拉伸人物。先检查原片画面和声音是否可用。
2. 从实际口播转写完整文字，提供用户核对。自动转写稿不能直接当“定稿逐字稿”；核对时只修正识别错误，不擅自重写用户所说内容。若用户另给逐字稿，逐处核对与原声的差异，再确定字幕文本。
3. 原片原声是最终声音与时间基准；按它对齐短语级字幕和镜头。不得调用 TTS 覆盖原声，也不得未经用户同意剪口误、删句、重排话语或改变隐私范围。若无法可靠转写，停在第一步，请用户提供文字或确认转写方式。
4. 原片仅作人物小窗的画面来源。渲染时只接入一次原声音轨，人物小窗视频层静音，避免重复音频。

## 分镜和真实素材

- 第二步按口播语义规划每个镜头；标明动效、真实操作录屏或截图，逐镜列所需素材及动效使用次数。已有口播原片不等于已提供软件操作录屏。
- 真实操作镜头只使用用户提供或明确授权获取的真实录屏或截图，记录来源。第三步给出明确的录制清单，素材获取后检查可读性、操作内容与分镜是否一致；已授权且可获取的素材不重复索取，缺少素材时标“缺素材”，不伪造界面。改成概念演示须先改分镜并获用户确认。

## 小窗与画面布局

- 人物从成片第一帧到最后一帧均保持小窗形式；不得切成 3:4 真人主画面。原片等比显示，裁切范围、人物位置和可辨识度通过静态图检查。
- 人物小窗的外形必须完整：使用方形或竖向矩形时，四个角都做圆角，画面、白色描边和裁切边界保持同一个圆角轮廓；使用圆形时，整个人物画面、描边和裁切边界均为正圆。不得留下直角矩形、只圆一部分角，或在圆角小窗背后露出方形底板。尺寸和圆角程度以用户已确认的参考图或项目视觉配置为准；没有参考时先做真实合成静态图确认。
- 圆角白边必须与人物画面严丝合缝：外框圆角半径为 R、白边宽度为 B 时，人物画面使用同心的内圆角 R-B，四条直边和四个角的白边厚度一致。不能先给直角人物画面补白再只裁外轮廓，避免弧角处看起来像两层拼贴。静态图放大检查四角和白边，确认没有露底、断边或不均匀缝隙。
- 参考图若是横向圆角小窗，应按参考图的宽高比裁取人物近景，不能把竖版口播原片等比缩小成竖长矩形；人物画面只做裁切与等比缩放，不拉伸。逐镜检查额头、下巴与肩部的裁切，避免动作时头部出框；右上位置和大小仍需以真实合成图检查遮挡。
- 动效模板作为完整的 1920×1080 画面保持原有居中构图；小窗作为独立上层叠加。即使小窗遮住动效局部，也不能为避让它而整体缩放、平移或挪动模板内部文字、贴纸和连线。若某模板原生构图无法满足居中要求，改选合适模板或提交新静态方案，不悄悄改模板。
- 小窗默认在右上角。若真实录屏的重要操作被遮挡，先只缩小小窗，并用**实际录屏**制作静态合成图供用户确认；缩小后仍看不清操作或人物时，提出备选布局并等待确认，不自动换角、不缩小录屏到无法阅读。真实录屏始终等比，不拉伸、不伪造、不错误裁切。
- 第四步至少展示“动效＋人物小窗”静态图；有真实录屏时再展示“实际录屏＋人物小窗”静态图。静态图确认后才制作动态样片。

## 样片与全片验收

- 样片必须带原片对应时段的声音；检查人物口型、原声、字幕与动效时间点同步。全片只保留一条清晰连续的口播音轨。
- 从最终导出的 MP4 逐镜抽看代表帧，核对人物小窗是否全程存在、动效是否居中、真实操作是否可辨、字幕和贴纸是否溢出或被挡。技术检查通过不等于用户确认最终画面。
