# 样片确认后快速制作全片

适用于用户关注“确认动态样片后，到完整初版完成技术与画面检查”的耗时。六步确认和 `qa-checklist.md` 的验收要求照常执行。计时从用户确认带声音样片开始，到完整初版通过 Codex 检查结束；用户最终确认与修改另记。

1. 从已确认的样片工程继续制作，复用镜头源码、视觉参数、字幕时间轴和最终声音。口播视频模式还复用已确认的人物小窗裁切与原片时间范围；不要把样片 MP4 嵌进全片，也不要重新制作已确认镜头。
2. 对剩余镜头中重复的录屏容器、文字层或背景建立可传参组件，再按已确认分镜和起止帧填入内容。只抽象重复结构，避免为了通用化开发新模板。
3. 一次组装全片时间线和单条口播音轨（逐字稿模式为配音，口播视频模式为原片原声），人物小窗视频层静音；先核对实际模板调用与分镜统计，再导出完整初版。检查发现具体问题时再修改并重渲染；保留所有返工耗时。
4. 按 `qa-checklist.md` 检查规格、音轨、字幕、关键帧和实际画面。将“技术检查通过”和“用户确认最终画面”分开记录。
5. 分别记录样片确认后的镜头制作与组装、渲染与封装、技术与画面检查、返工，以及等待用户的时间。若此前已制作全片通用工程或剩余镜头，也记录这段准备时间，不能只报确认后的数字。报告实测耗时，不把单次结果写成固定承诺。
