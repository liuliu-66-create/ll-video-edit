# 模板规则索引

使用模板前，先在 `library.json` 找到场景，再阅读对应的 `TEMPLATE.md` 和 `layout.json`。

## 已通过模板

| 场景 | 规则说明 | 布局参数 |
| --- | --- | --- |
| 多点列举 | `multi-point-list/TEMPLATE.md` | `multi-point-list/layout.json` |
| 流程步骤 | `process-flow/TEMPLATE.md` | `process-flow/layout.json` |
| 前后对比 | `before-after-compare/TEMPLATE.md` | `before-after-compare/layout.json` |
| 概念解释 | `concept-explainer/TEMPLATE.md` | `concept-explainer/layout.json` |
| 重点结论 | `key-conclusion/TEMPLATE.md` | `key-conclusion/layout.json` |

## 固定门槛

每确认一个新模板，必须先完成该模板的规则说明、布局参数、边界检查和总表登记，才能开始下一个模板。
